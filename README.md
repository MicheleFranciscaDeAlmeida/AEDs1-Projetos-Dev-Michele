# AEDs1-Projetos-Dev-Michele
Implementações em Algoritmos e Estrutura de Dados I em C e C++

Projeto de AEDS 1 - Manipulação de Dados de Aluno com a estrutura de dados Struct em Linguagem C.

Visão e Objetivo do Projeto:
Este projeto demonstra a implementação e o uso básico de uma Estrutura de Dados (struct) na linguagem C para organizar informações relacionadas a um único registro de aluno. Ele serve como um exercício fundamental na manipulação de tipos de dados definidos pelo usuário e o acesso a membros da estrutura.

Tecnologias utilizadas:
Linguagem de Programação em C;

Conceitos chave de AEDS1: 
Estrutura de Dados - Struct e Manipulação de Strings.

Conceitos e finalidade:
O código ilustra a definição e a utilização de uma struct chamada Aluno, que agrupa diferentes tipos de dados sob um único nome.

Definição de struct: 
Criação de um tipo de dado personalizado que contém: nome (Array de char / String), matricula (int), mensalidade (float), nota1 e nota2 (float) e media (float).

Acesso a Membros: 
Utilização do operador ponto (.) para acessar e modificar campos individuais da estrutura (aluno.matricula, aluno.nome, etc.).

Cálculo Algorítmico Simples: 
Implementação do cálculo da média aritmética das duas notas do aluno.

Segurança de String: 
Demonstração do uso de strncpy e do terminador nulo (\0) para copiar strings de forma segura, prevenindo potenciais estouros de buffer.

Como executar e compilar esse código?
Esse é um código bem simples em c, que poderá ser compilado e executado em qualquer IDE disponível atráves do Windows ou Linux, como Codebloks, VsCode,DevC++, entre outras, pórem exige a instalação do compilador gcc para executá-lo e compilá-lo de forma eficaz.

Como salvar um arquivo em Linguagem C?
Assim que terminar de codar o código e executá-lo, salve o arquivo na área de trabalho ou onde preferir com a seguinte extensão .c, exemplo: exercicio1.c .
